固定比较口径

始终使用牛奶语言、原始布局、环境第 0 步；平均 8 个 heads 和前 5 个动作位置，不包含 state query。correct = 牛奶示范 814；wrong = 番茄酱示范 821；no = 示范值与 mask 关闭。

相同初始噪声 ≠ 每次后续更新的动作候选相同。采样步 9 的差异包含 context 在前面采样更新中的累积影响。采样步 0 可查看首次更新；同一次前向内部的各层也会受 context 影响。

1. 先并排看热点与相机总量

颜色表示对全部 keys 的直接 attention 权重。相机内部热点有空间索引，但图像 token 已混合上下文信息，不能直接当成像素因果归因或物体检测。移动到热图上可读单个 patch 的数值。

2. 单独看空间分布改变了多少

先把每个相机内部归一化到 100%，再减去 correct 的分布。这一步去掉相机总量变化，只比较相对份额在哪些位置增加或减少。红色增加，蓝色减少。同相机的两个差值图共用对称刻度。

TV = 两个相机内分布的绝对差之和 ÷ 2，范围 0–1。它是空间重分配的描述量，不是显著性检验、行为成功率或因果重要性。不同相机的差值图刻度可以不同。

先回答一个有限的问题

默认层/采样步下，correct 与 wrong 的平均热图较接近，no 与 correct 的空间差异更明显；其余四个初始状态也出现了这个相对关系。请切换初始状态核对，不要只看主例。

目前不能从这些平均热图证明“关注从牛奶明确转移到了番茄酱”。没有物体区域标注，不能把背景/夹爪热点自动算到某个物体。热图接近也不代表行为一定接近：这里没有展示 value、残差、单个 head 或所有动作位置。
