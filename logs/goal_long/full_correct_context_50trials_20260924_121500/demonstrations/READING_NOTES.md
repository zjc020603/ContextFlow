# 两个失败任务怎么对照示范

1. Task 1 实际使用 episode 1（284 帧），Task 5 使用 episode 8（259 帧）。它们不是新挑选的示范；均与本次服务输入核对过。完整视频可检查示范动作顺序，8 帧图则用于检查模型视觉上下文实际保留了哪些阶段。
2. Task 1 的“抓到杯子”尚未做全部 50 回合的抓取事件统计，不能写成 100%。原目标统计显示：杯子在盘子上的条件曾有 6/50 次成立，结束仍成立为 2/50；布丁目标始终 0/50。说明失败不全是一次都无法放置，也包含放置后没有保持条件的情况。它没有外加“杯子成功才准做布丁”的阶段控制器，行为顺序由策略自己产生。
3. Task 4（汤罐＋奶油奶酪，seen）的汤罐条件曾有 49/50 次成立，结束仍成立 48/50。Task 5 两个目标都未成立；这支持检查技能能否在新配置中被调用，不能单凭此断言从未学会抓汤罐。Task 5 的 BDDL 比 Task 4 多 orange_juice、milk、butter 三类物体，画面中的干扰与布局也不同。当前对照没有控制这些差异。
4. 没有统计抓取成功率，也没有通过这些视频证明因果机制。本页只补充本轮真实示范，原始成功率不变。
